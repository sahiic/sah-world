# Focus ambient placeholders

Bu klasör ambient ses motorunun beklediği dosya yollarını belgeler. Telif ve
boyut kararı verilene kadar ses dosyaları bilerek repoya eklenmemiştir.

Beklenen dosyalar: `rain.mp3`, `birds.mp3`, `wind.mp3`, `ocean.mp3`,
`fireplace.mp3`, `forest.mp3`, `white-noise.mp3`, `brown-noise.mp3`,
`pink-noise.mp3`, `quran-tilawah.mp3`, `tasbih-ambient.mp3`,
`mosque-ambience.mp3`.
